# uni-labs
Assignments completed at the university.
This project demonstrates progressive development of a C++ application, covering key programming concepts and best practices.
## Lab 1
Function Overloading, Dynamic Memory, I/O
- Use of overloaded functions, new, delete, cin, cout, and references (&)
- Dynamic allocation (new, delete)
- Arrays of objects and pointers (1D & 2D)
- Function overloading, cin / cout, references
## Lab 2
String Processing & Data Handling
- Input parsing using getline()
- Data validation and type conversion
- Random data generation
- Aggregation between structures
## Lab 3
Object-Oriented Programming
- Transition from structures to classes
- Encapsulation (private attributes)
- Constructors, destructors, initializer lists
## Lab 4
Advanced Class Features
- Copy constructor
- Nested classes
- friend relationships
## Lab 5
Operator Overloading & File I/O
- Overloaded operators: <<, >>, =, []
- File reading and writing
- Formatting with <iomanip>
## Lab 6
Inheritance & Polymorphism
- Abstract base classes
- Derived classes and dynamic behavior
- Static object usage
## Lab 7&8
STL Containers
- Sequential containers (vector)
- Associative containers (map, set)
- Custom comparators
- Refactoring from raw pointers to STL
